Job Portal - React App
This is a Job Portal web application built using React and React Router. Users can browse job listings, apply for jobs, and filter jobs based on categories.




🛠 Tech Stack
Frontend: React, React Router
State Management: Context API
Styling: CSS
Deployment: Vercel (optional)




🚀 Features
✅ View All Jobs - Browse a list of available jobs
✅ Apply for Jobs - Fill out a form and upload a resume
✅ Filter by Category - View jobs by category (e.g., Consulting, IT, etc.)
✅ Navigation - Seamless routing with React Router
✅ Success Page - Confirmation page after applying for a job
